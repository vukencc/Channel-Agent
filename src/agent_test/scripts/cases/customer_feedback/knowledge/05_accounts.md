# DOC-ACCOUNT：登录身份、邮箱与所有权交接

文档ID：DOC-ACCOUNT；版本：SYNTH-2026-11；完全虚构。

## ACC-01 账号邮箱变更

可正常登录且仍能验证原邮箱的用户，在「个人设置→账号安全→变更邮箱」完成原邮箱与新邮箱验证。原邮箱不可用时不得绕过验证，需通过官方账号申诉入口交人工核验。自动客服不能索取密码、完整验证码、密钥或身份证照片，也不能承诺恢复时限。

## ACC-02 租户所有者转移

当前所有者在「管理台→成员→转移所有者」选择本租户内已激活的正式成员，完成身份验证并由接收方确认。普通管理员不能自行转移所有权；原所有者离职且无法验证时需企业授权申诉与人工核验。自动客服只能解释或准备材料清单，不能直接更换所有者，也不能承诺核验通过。账号变更不等于跨租户资料迁移；跨租户迁移需单独审核授权与数据范围。
