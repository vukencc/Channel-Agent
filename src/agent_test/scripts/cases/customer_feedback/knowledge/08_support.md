# DOC-SUPPORT：自动帮助、人工升级与需求登记

文档ID：DOC-SUPPORT；版本：SYNTH-2026-11；完全虚构。

## SUP-01 自动帮助已无效

客户明确表示此前自动客服、机器人或自动引导已经尝试且未解决，即应转人工客服。表达可以是「照机器人做了还是不行」「上次自动答复不适用」「智能助手让我绕圈」等，不要求固定关键词。承认此前帮助未解决，准备含反馈ID、问题、已尝试步骤、尚缺信息的交接摘要，避免让客户从头重复。可以提供仍有用的政策解释，但不能把再次自助作为转人工前提。

## SUP-02 首次咨询与承诺边界

首次咨询、仅浏览普通文章、引用别人失败经历或担心自动帮助可能无效，不等于本人此前自动帮助失败，不应自动触发SUP-01。需人工审核的退款/身份事项可说明审核入口，与「自动帮助失败转人工」分别记录。只有真实受理系统返回成功与工单编号时，才可说已提交人工队列；即使已提交也不能说人工已接单、已处理、保证时限或退款已批准。此业务夹具没有真实人工受理接口，输出只能标记需要转人工并准备交接。

## SUP-03 新功能建议

新功能建议属于需求服务，可记录场景、影响、期望行为与优先程度，准备产品需求摘要。不得承诺排期、交付日期、开发已启动或功能已经支持。现有能力与套餐以对应政策为准，知识库没写的能力先说明未确认，不能猜测。
