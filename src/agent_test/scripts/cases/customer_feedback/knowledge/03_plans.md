# DOC-PLAN：套餐升级、降级与续费

文档ID：DOC-PLAN；版本：SYNTH-2026-11；完全虚构。

## PLN-01 套餐能力与升级

基础版最多5个正式成员，不含SAML单点登录；标准版支持购买更多席位，仍不含SAML；企业版支持SAML，需商务审核。试用不等于购买，也不承诺任何功能定制上线。所有者从「管理台→订阅→变更套餐」查看报价，升级在支付成功且系统确认后生效，差价以结算页为准，自动客服不能自行报价或承诺折扣。

## PLN-02 降级

降级默认下个计费周期生效。降至基础版前须把正式成员调整至不超过5人并确认企业版专有能力的停用影响；未满足条件不能承诺降级成功。降级不自动产生当期退款。不知道套餐或成员数时先询问，不能把猜测写成账户事实。
