# DOC-INVOICE：开票与抬头修改

文档ID：DOC-INVOICE；版本：SYNTH-2026-11；业务与政策完全虚构。

## INV-01 自助开票

已支付且未退款订单，由租户所有者或财务管理员在「管理台→账单→发票」勾选订单，填写企业抬头与税号，提交审核。相同订单不可重复开票。审核通常需3个工作日，这是预计时长，不是保证；无权账号请联系本租户所有者授权财务角色。

## INV-02 已开票更正

已经开具的发票不能直接编辑抬头。需在发票详情发起更正审核，提供合成发票/订单编号及需更正字段，由财务核验后处理作废或红冲及重开。自动客服不得声称已作废、已红冲或已开新票。自动流程无法解决时应转人工，不能反复要求客户重复同一无效步骤。
