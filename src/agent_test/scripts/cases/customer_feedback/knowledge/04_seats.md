# DOC-SEAT：席位、访客与成员移除

文档ID：DOC-SEAT；版本：SYNTH-2026-11；完全虚构。

## SEA-01 席位计数

正式成员占用付费席位；仅有指定项目查看权限的访客不占付费席位。待接受的邀请也不占席位，但邀请被接受时必须有可用席位。「管理台→成员」显示成员角色与可用席位，不能只看邀请数量判断是否超额。

## SEA-02 释放席位

所有者或有成员管理权限的管理员先完成项目及资料交接，再移除正式成员以释放可用席位。移除成员不会自动减少已购席位数，也不自动产生退款。减少续期席位需在「订阅→席位」另行设置，下周期生效；不得替客户擅自删除成员或资料。自助步骤失败时依SUP-01准备人工交接。
