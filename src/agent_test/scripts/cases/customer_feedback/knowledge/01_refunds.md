# DOC-REFUND：退款申请政策

文档ID：DOC-REFUND；版本：SYNTH-2026-11；业务：完全虚构的星桥协作。

## REF-01 首次付款申请条件

首次购买标准版的租户，在首次付款后7个自然日内且尚未生成正式发票，可提交退款审核申请。7日从付款时刻起算；该条件只是进入审核，不等同必然退款。自动续费、升级差价、已开发票或超过7日的订单不能直接套用此规则，需人工按订单事实审核。

## REF-02 申请步骤与边界

租户所有者在「管理台→账单→订单→申请售后」提供合成订单编号、付款时间、购买类型与退款原因。自动客服可解释政策和准备摘要，不得承诺批准、具体到账时间、退款金额，不得声称已经提交或执行退款。不要索取完整银行卡号、密码或验证码。自动帮助已经失败时，依 DOC-SUPPORT 的 SUP-01 转人工并附已尝试步骤。
