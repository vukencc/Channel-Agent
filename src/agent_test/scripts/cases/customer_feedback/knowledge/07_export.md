# DOC-EXPORT：项目资料导出与数据边界

文档ID：DOC-EXPORT；版本：SYNTH-2026-11；完全虚构。

## EXP-01 导出权限与范围

项目所有者或具有导出权限的管理员可在「项目设置→数据导出」申请导出任务，选择项目及日期范围。导出包含可访问的任务与文档正文，不含密码、密钥、聊天私信或未授权项目。先检查权限和范围，不得扩大访问权限绕过限制。

## EXP-02 任务与文件

任务完成后在导出记录中下载，下载链接24小时有效。导出任务通常在1个工作日内生成，这是预计时长，不是保证。自动客服未看到任务结果不得声称已生成文件，不得虚构下载地址。首次咨询解释步骤；任务明确报错属技术问题，需保留任务ID、错误与时间交技术分析。
