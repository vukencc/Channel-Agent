# Agent Flow 创作功能验证（2026-11-02）

> 文档类型：历史报告 · [当前阶段状态](project-status.md) · [文档导航](README.md)。保留当时的结果与失败；旧路径、默认值及本地产物不作为当前使用要求，也不保证随 clone 提供。

## 交付范围

原生 GUI 与 WebUI 同步提供右侧设计对话、节点工具/模型/思考配置、便携 JSON 导入导出。现有 Flow 画布、项目与模板分离、工作区边界和逐节点执行方式保留；本轮没有新增依赖或环境变量，也没有把既有客服业务测试的失败改称通过。

设计助手使用所选真实模型和多轮历史，只返回经校验的模板；没有文件、命令或执行节点能力。生成成功自动创建独立模板副本，不覆盖原图、不绑定项目、不启动 Flow。历史有界，上一版模板过大不能完整纳入时明确提示。无活动 Flow 也可打开助手；有 Flow 时保留画布，两端侧栏可关闭，窄窗口可切换检查器。

节点默认继承工具目录，显式空列表只保留 `read_file`、`list_files`，可选能力由用户勾选。请求 schema 与实际执行共用部署及祖先有效上限；基础工具不突破部署配置。思考/推理配置进入实际请求，`disabled` 不发送 reasoning；不同 provider 的参数支持仍需用户使用对应模型，系统不猜测或静默修改参数。

便携模板采用 `format: agent-flow`、`version: 1`，保留节点 ID 与配置，移除运行、项目身份及工作区路径，不包含模型连接凭据。导入完整验证后一次写入新模板，坏版本、循环、未知工具/模型或越界路径不残留空模板；未知模型只有明确选择继承时才替换。文件不打包交接文件、知识库或模型。

## 验证结果

- 最终非集成回归：**1774 passed、2 skipped、5 deselected（107.22秒）**。两项跳过为可选 ANN 依赖；此前1755和1772项回归不包含随后补充的全部边界，以本次最终结果为准。
- 工具/沙箱：真实 Bubblewrap + prlimit 探针通过。新增完整 Flow 回归用受控模型尝试调用已禁用命令，得到实际拒绝结果且未创建标记文件；同时检查自定义/继承模型、思考和推理参数及请求工具目录。
- 真实模型设计：`deepseek-v4.1-flash` 一次真实 provider 请求，7.080秒，返回3节点2连线；模型提供的工具配置满足仅基础读取、服务节点额外RAG、禁命令与委派。实际导入、导出、再次导入生成新ID，未创建运行会话或项目。该结果证明模板创作链路，不代表这三个节点执行过业务。
- 实际 Chromium：真实静态资源与HTTP接口，模型为明确的受控回调。验证三节点生成、画布旁继续第二轮、上一版完整模板上下文、节点模型/思考/强度及基础锁定、草稿导出、文件导入副本、坏版本不新增记录、停止不导入迟到结果；450px无文档横向溢出，关闭聊天仍可看画布，页面脚本异常0。
- Chromium 启动/取消：仅延迟真实元数据响应，不替换返回内容，确认启动时立即进入设计不会被欢迎页覆盖、已输入文字保留、模型名称和选中项刷新正常。让受控模型真实进入等待后点击停止，服务端协程收到取消，未创建模板。这与未发出请求便停止的检查分开记录。
- 实际 WSLg：真实 Wayland `MainWindow`、`RuntimeBridge` 与 QTest，独立状态和受控模型，验证两轮设计、节点配置、实际文件往返、手动模板切换、取消及安全退出。1280/560/450px检查，450px设计栏230px、画布178px；窄屏检查器与聊天切换不互相遮挡，工具列表可滚动。不是用户物理鼠标验收或真实provider测评。
- 构建：Core与Frontend wheel成功生成；新模板/设计模块及原生/Web资源与当前源码逐项核对。当前指南本地引用、差异和用户数据保留检查通过。

浏览器依赖缺失时只在本轮临时目录下载并解包运行库；中文字体通过验证进程读取本机 Windows 字体，未安装系统包或改产品字体配置。CSP不允许字符串eval、隐藏重复对话框和基础工具在运行时补齐等测试驱动问题均修正到实际API语义，没有放宽产品断言或替换HTTP结果。

## 测试中修复的缺陷

1. 便携节点schema曾包含禁止导入的workspace字段，已改为专用schema，真实模型看到的格式与验证一致。
2. 子会话分支曾能从父原始工具记录恢复已被祖先禁止的能力；现在遍历完整祖先链、缺父无快照或成环则关闭工具。新分支持久化有效上限，删除来源前再收敛存活后代快照，避免恢复旧权限；保存失败中止归档，并阻止归档间并发扩权。
3. 原生多轮对话曾只传回复、不传模板；现两端都保留实际图作为后续上下文，超长时明确提示。
4. Web设计最初替换整个画布，现改为旁侧对话。初始化及模型库异步刷新不会关设计栏、抹输入或丢模型选择。
5. Web单靠断连检测不能可靠停止模型，现使用请求ID和独立取消接口，处理取消先到、旧取消与新任务隔离；实际浏览器已验证服务端取消。收尾还复现了显式停止引发ASGI无响应异常，现模型子任务取消返回HTTP 499，HTTP请求自身取消仍传播并等待模型结束；新增两项回归及实际浏览器复验通过。
6. 原生窄窗口有最低宽度与面板遮挡，已补450px布局；导出多请求曾共享一个目标路径，现一次仅处理一个，结果完成前保持禁用，真实慢响应文件回归确认不串写。

停止发生在模型生成期间会取消请求；若导入副本已在服务端提交，随后停止不会撤销该副本。助手与模板编辑历史只保留当前窗口，不承诺跨应用重启恢复；模型服务不支持某项思考参数时会报错。
