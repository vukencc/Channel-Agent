## 三个节点的任务

1. **契约设计**：首先检查空目录，只编写 `CONTRACT.md`，明确接口、数据、前端行为和测试步骤，将方案交给下游。
2. **前后端实现**：阅读实际交接与契约，完成标准库 HTTP 后端、原生 HTML/CSS/JS 前端、说明和基础测试，运行后交接。
3. **独立验证修复**：阅读实际交接，运行单元与 HTTP 集成验证，检查重启持久化；发现缺陷时自行修复并重跑，写入 `VERIFICATION.md`。

统一契约：`python app.py --host 127.0.0.1 --port PORT --data-file ABS_JSON` 启动；提供任务列表、创建、修改、删除、完成/待办筛选和统计。任务包含字符串 ID、去首尾空白的 1–120 字符标题与布尔完成状态。无效 JSON、字段类型、空 PATCH、非法筛选返回 JSON 400；未知 ID/API 返回 JSON 404。页面具有实际表单和创建、切换、删除、筛选行为，引用 `/static/style.css`、`/static/app.js`。数据采用 JSON 持久化，重启保留变更，删除后的 ID 不复用，不访问项目外文件。

独立验收器为 `src/agent_test/scripts/validate_flow_fullstack.py`。它启动实际业务进程，使用自己的临时数据文件，以 HTTP 核对结果，不补写 Agent 业务代码。它不能替代真实浏览器交互检查。
