# 工作区共享记忆

> 文档类型：当前使用指南 · [文档导航](README.md) · [上下文管理](context-management.md) · [Agent Flow](agent-flow.md)

绑定同一实际项目工作区的会话、Flow 节点和使用不同状态目录的应用实例可复用有界项目摘要；不同工作区不共享。首次允许更新时，应用在工作区创建 `.channelagent/memory.json`。每次模型调用前安全读取现有快照；只读和没有快照的读取不会创建文件。它属于应用运行数据，与 Codex 配置和开发子代理无关。

## 配置与内容

应用的 `WORKSPACE_MEMORY_ENABLED` 默认 `true`；设为 `false` 后不再自动读写，已有文件保留。`WORKSPACE_MEMORY_INJECT_CHARS` 默认 6000，允许 256–12000。注入还受本轮字符及 token 输入预算各四分之一限制，计入普通或结构化上下文窗口预算。快照标记为不可信参考，不能作为系统指令、用户授权或业务验收证明；应核对实际项目文件和结果。

快照是单个原子 JSON，含版本、递增修订号和 UTC 更新时间；`project` 最多 48 条事实，`progress` 最近 24 条进度含 UTC 时间、`idle`、`checkpoint` 或 `error` 状态、自报摘要及不含会话 ID 的更新标识，`lessons` 最多 48 条经验。大小上限 128 KiB；超出时按字节占用裁剪旧记录，保留各部分最新记录。私有 `.agent/` 会话记忆、消息、推理、收件箱及审计不会迁移到此文件。原有 `MEMORY_SHARED` 和 `ENABLE_MEMORY_MANAGEMENT` 是独立的会话记忆配置，不控制此功能。

## 更新与权限

本轮排队输入和私有终态成功保存后，正常结束会额外发起一次辅助模型请求，仅用本轮当前请求和最后可见回复提炼公开项目事实、进度和经验，不输入旧对话、工具原文、思考过程或私有记忆。已知配置凭据在提炼前及写入前遮盖；脱敏不是通用数据防泄漏机制，摘要可能出错，不建议放入隐私数据。`AUX_MODEL` 留空时使用该会话所选连接，显式配置时沿用辅助模型设置；请求和费用计入同一预算所有者，受 `AUX_TIMEOUT` 或 `ASSESS_TIMEOUT` 限制，不自动重试。判定与项目无关的闲聊时跳过共享记录；摘要格式错误或超时仅保存说明摘要失败的通用进度，不编造事实或经验。检查点和错误只记录状态；排队或首次终态保存失败不发布。

`readonly` 仅读取，不创建文件或锁，也不发送提炼请求；FullAccess 自动更新，Smart 对框架限定的 `.channelagent/memory.json` 元数据更新自动授权，其他文件的覆盖确认不变；历史 standard/trusted 模式仍需确认。拒绝后不写入。更新在会话任务结束前同步提交，因此 Flow 下游等待前节点的记忆落盘。写入或完成审计失败时标记失败或状态不确定并进入检查点，阻断下游；原业务回复保留。状态不确定时先核对文件，勿重放已执行操作。

## 文件和恢复

符号链接、硬链接、工作区根身份变化、损坏 JSON 或超限会被拒绝，原文件保留。目录锁 `.channelagent/.write-lock` 用原子目录创建协调遵守协议的框架多进程写者，等待最多 3 秒并支持取消；崩溃遗留的锁不会自动破除。确认所有应用已停止后，可仅手动删除空锁目录，不要清除记忆数据。合法本地命令和用户仍可编辑工作区文件，锁不约束外部写者。

取消会阻止尚未开始的后续提炼和发布；若写入已经提交，不会回滚已保存的共享记忆。写盘期间停止时先排空实际操作，再保存一致的取消终态。Flow JSON 模板导出不包含工作区记忆；复制工作区会携带共享摘要，私有会话须另行管理。Git 不会自动忽略该目录，应用也不自动修改 `.gitignore`；按共享需求自行决定是否忽略。检查项目内容与权限后再复制或共享工作区。
