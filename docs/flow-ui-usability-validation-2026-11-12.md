## 全量回归发现与针对性修复

首轮 Linux 全量为 2 failed、2167 passed、39 skipped、5 deselected（179.62 秒）。两项失败均在原有项目选择回归：压缩工具栏后项目按钮被收进更多菜单，以及工作区摘要仅保留目录名。修复保留主栏可见项目按钮；完整路径保存在标签和提示中，仅绘制时省略，窄窗将检查器/设计助手入口放入更多菜单。原有项目按钮可见、位置和完整路径断言保留，并扩展到 500/560 像素及窗口不横向增长检查。

只读复核还发现普通 Flow 快照没有权威子 Agent 计数、模型菜单缓存会保留已删除连接。现在 Flow 概要省略未知计数，Working 使用权威实时计数；模型刷新清理失效项，并保留有效选择和进行中请求的参数快照。补充了模型列表刷新不打断正在选择的项目，以及不自动选择未配置环境预设的回归。


第二轮全量为 2 failed、2170 passed、39 skipped、5 deselected（176.05 秒）：新增的 500/560 像素不横向增长断言发现，旧宽窗工具栏最小尺寸会将请求宽度钳制到 612 像素。现先允许按目标宽度调整，再根据宽度将辅助动作移入更多菜单；桌面完整测试组随后 143 项通过。原有宽度、项目入口和完整路径断言均保留。
