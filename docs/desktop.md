# 原生桌面 GUI

Windows 原生运行与 WSL 隔离命令的安装步骤见 [Windows 指南](windows.md)。

> 文档类型：当前使用指南 · [文档导航](README.md) · [快速上手](getting-started.md)

桌面客户端使用 Qt Widgets，直接调用 AgentCore，不启动 HTTP 服务，不嵌入 WebView，也不需要浏览器。WebUI 也提供 Agent 与 Flow 入口；CLI 提供会话入口。

## 启动

在 Linux 或启用 WSLg 的 WSL 中，从仓库根运行：

```bash
uv sync --locked --extra desktop --extra web
uv run --no-sync ai-agent-gui
```

`--extra web` 用于保留现有 WebUI 的可选依赖；只使用桌面时可以仅安装 `--extra desktop`。桌面依赖为 `PySide6-Essentials`，包含原生控件，不安装 Qt WebEngine。Linux 需要可用的图形会话和中文字体；WSLg 可复用宿主已有的微软雅黑字体，普通 Linux 可安装 `fonts-noto-cjk`。Windows 宿主使用 WSL checkout 时，在 WSL 内用 Linux `uv` 启动 Qt，由 WSLg 显示窗口；不要对该 `.venv` 使用 Windows `uv`。Windows 原生和 Linux 成品另见 [Windows](windows.md)与 [Linux](linux.md)指南，使用各自独立的运行环境。

默认继续使用根 `.env` 和既有会话目录。独立测试或需要单独的会话库时：

```bash
uv run --no-sync ai-agent-gui --state-dir /绝对路径/独立状态目录
```

同一状态目录同时只能由一个 CLI、WebUI 或桌面进程持有。模型尚未配置时仍能打开窗口，在“模型管理”中添加连接后使用。

## 使用

界面使用统一的深色工作台和浅蓝强调色，以背景层级、细分隔线和留白区分区域。主面板采用直边，按钮、输入和列表项保留 3–4px 小圆角，状态点和 Flow 端口保留圆形。欢迎建议、消息/代码/工具内容、模型管理、项目选择、设计助手和检查器沿用同一层次。左栏提供新建、搜索和切换会话；中央保留对话、任务状态和自适应输入框。设置、模型管理和活动详情按需打开。

- `Enter` 发送，`Shift+Enter` 换行；停止按钮或 `Esc` 取消当前运行。
- 欢迎页的任务卡片只填入草稿，不自动发送；窄窗口自动收起会话栏，仍可手动展开。
- `Ctrl+N` 打开新建项目对话框，可选择经典 Agent 或 Flow；`Ctrl+L` 聚焦输入，`Ctrl+B` 隐藏或展开会话栏。
- 阅读旧消息时不会因新输出自动跳到底部；“回到最新”恢复跟随。较长历史按页加载。
- 会话设置提供模型、项目目录、命令环境和权限模式；子 Agent 沿用父项目与环境。
- 经典 Agent 工具由框架管理，不提供会话工具清单选择；Flow 节点可在部署上限内选择工具。旧会话和部署策略中的能力上限继续生效。
- 工具确认使用原生对话框，确认绑定具体会话和请求。关闭窗口会先取消任务、等待工具与持久化排空，再释放状态目录。

模型密钥只在密码框输入；模型列表不返回密钥，保存或取消后清空输入。对话支持安全的标题、列表、强调、行内代码与围栏代码块；流式输出中尚未闭合的代码围栏也可阅读。链接、图片和原始 HTML 保持为转义文本，不会隐式读取本机文件或联网加载资源。输入框与模型参数编辑器只接受纯文本，避免粘贴或 JSON 字面内容被当作富文本解释。

## Agent Flow

左栏可独立创建 Flow 模板；新建 Flow 项目可导入模板副本或从空白流程开始。项目选择已有工作区后才能运行，所有节点使用该项目目录。画布支持添加、拖动节点与连接端口，并提供可视化目录选择。交接会沿连线自动传递，已有背景放在可选补充区，节点职责填写在“节点指令”。保存、运行和中断恢复详见 [Agent Flow 指南](agent-flow.md)。

右侧设计助手支持多轮设计，可隐藏并保留草稿与请求，清空对话或停止则取消当前请求。节点右键打开检查器；设计助手与检查器共用可关闭的右侧区域。悬停节点可查看概要，Working 节点也可右键查看详情。节点检查器可设置工具、模型、推理和可选的结构化交接契约，运行详情显示格式验收结果。画布支持便携模板导入导出，具体边界见上述指南。

运行状态与操作确认采用后台当前快照；完成后的面板状态在延迟操作确认返回后保持一致。画布「适配」只会缩小过大的图，不会将少量节点自动放大；用户仍可手动放大查看。

## 模块边界

界面与线程桥接在 `src/agent_frontend/desktop/`。Qt 主线程只接收 JSON 快照和操作结果，Core 管理器由后台 asyncio 循环独占。Debug 记录器仍由 AgentTest 提供，原生 GUI 不把调试实现搬回内核。

工具简化的具体决定与兼容行为见[工具设计](tool-design.md)。
