# 原生桌面 GUI

桌面客户端使用 Qt Widgets，直接调用 AgentCore，不启动 HTTP 服务，不嵌入 WebView，也不需要浏览器。WebUI 也提供 Agent 与 Flow 入口；CLI 提供会话入口。

## 启动

在 Linux 或启用 WSLg 的 WSL 中，从仓库根运行：

```bash
uv sync --locked --extra desktop --extra web
uv run --no-sync ai-agent-gui
```

`--extra web` 用于保留现有 WebUI 的可选依赖；只使用桌面时可以仅安装 `--extra desktop`。桌面依赖为 `PySide6-Essentials`，包含原生控件，不安装 Qt WebEngine。Linux 需要可用的图形会话和中文字体；WSLg 可复用宿主已有的微软雅黑字体，普通 Linux 可安装 `fonts-noto-cjk`。本轮以 Linux/WSLg 为验证平台。

默认继续使用根 `.env` 和既有会话目录。独立测试或需要单独的会话库时：

```bash
uv run --no-sync ai-agent-gui --state-dir /绝对路径/独立状态目录
```

同一状态目录同时只能由一个 CLI、WebUI 或桌面进程持有。模型尚未配置时仍能打开窗口，在“模型管理”中添加连接后使用。

## 使用

界面使用统一的炭灰与浅蓝主题、原生矢量图标和分层消息样式。左栏提供新建、搜索和切换会话；中央保留对话、任务状态和自适应输入框。设置、模型管理和活动详情按需打开，避免常驻多块监控面板。

- `Enter` 发送，`Shift+Enter` 换行；停止按钮或 `Esc` 取消当前运行。
- 欢迎页的任务卡片只填入草稿，不自动发送；窄窗口自动收起会话栏，仍可手动展开。
- `Ctrl+N` 打开新建项目对话框，可选择经典 Agent 或 Flow；`Ctrl+L` 聚焦输入，`Ctrl+B` 隐藏或展开会话栏。
- 阅读旧消息时不会因新输出自动跳到底部；“回到最新”恢复跟随。较长历史按页加载。
- 会话设置提供模型、项目目录、命令环境和权限模式；子 Agent 沿用父项目与环境。
- 工具由框架自动管理，桌面、Web 和 CLI 均不提供工具清单选择。旧会话和部署策略中的能力上限继续生效。
- 工具确认使用原生对话框，确认绑定具体会话和请求。关闭窗口会先取消任务、等待工具与持久化排空，再释放状态目录。

模型密钥只在密码框输入；模型列表不返回密钥，保存或取消后清空输入。对话支持安全的标题、列表、强调、行内代码与围栏代码块；流式输出中尚未闭合的代码围栏也可阅读。链接、图片和原始 HTML 保持为转义文本，不会隐式读取本机文件或联网加载资源。输入框与模型参数编辑器只接受纯文本，避免粘贴或 JSON 字面内容被当作富文本解释。

## Agent Flow

新建项目时选择 Flow，或从左栏“Agent Flows”打开已有流程。画布支持添加、拖动节点与连接端口；画布上方及检查器可打开可视化目录窗口，显示流程默认项目和节点继承来源。交接会沿连线自动传递，已有背景放在可选补充区，节点职责填写在“节点指令”。保存、运行、项目继承和中断恢复详见 [Agent Flow 指南](agent-flow.md)。

## 模块边界

界面与线程桥接在 `src/agent_frontend/desktop/`。Qt 主线程只接收 JSON 快照和操作结果，Core 管理器由后台 asyncio 循环独占。Debug 记录器仍由 AgentTest 提供，原生 GUI 不把调试实现搬回内核。

工具简化的具体决定与兼容行为见[工具设计](tool-design.md)。
