# 配置说明

`.env.example` 是当前完整配置参考模板。首次安装时可复制为 `.env`；之后不要再次复制覆盖本地文件。进程环境变量优先于 `.env`，因此服务凭据与部署参数应以本机配置为准。修改配置后重启进程生效。

模板按功能分组；除显式保留的 `REASONING_EFFORT=low` 和 `THINKING_MODE=disabled` 服务示例选型外，其余值对应当前代码默认值。布尔项支持大小写形式的 `true`/`false`（模板保留原有 `True`/`False` 写法），JSON 配置项须保持合法 JSON；路径相对项目根目录解析。不要把密钥提交到仓库。

## 配置同步

`uv run python scripts/sync_env.py --check` 只检查 `.env` 是否缺少模板键或布局与模板不同：无差异退出码为 0，差异为 1，执行异常为 2。输出仅含统计与键名，不显示配置值。

`uv run python scripts/sync_env.py --write` 将本地 `.env` 按模板顺序整理，保留已有赋值的原始写法、注释、引号和变量引用，也保留模板之外的本地键及独有注释；缺少的键采用模板值，已有值优先。它不会把变量引用展开后写回，也不会删除本地自定义值。同步采用原子替换、不跟随符号链接，不创建包含秘密的备份副本；目标文件权限为 `0600`，只读检查不会改权限；目标不存在时会新建。可用 `--template`、`--target` 指定测试路径。完成后重启应用。

重复键、无效语法或重排会改变旧变量引用结果时，同步应拒绝写入；先修正本地引用顺序或环境变量后再运行。`--check` 不修改文件。

## 功能索引

- 模型端点、模型名、推理选项、备用模型、费用预算：见模板“模型服务与费用”及“请求、上下文与并发”。费用是本地估算，不是服务商账单上限。
- 工具许可、文件根目录、命令沙箱、网络访问和资源限额：见[沙箱说明](sandbox.md)与[命令工具说明](cli.md)。授权策略不会取消路径边界、确认流程或审计。
- RAG、嵌入模型、重排器、向量索引和缓存：见[RAG 文档](rag.md)。修改检索阈值前应使用质量集验证。
- 会话、后台命令、Agent 委派和任务计划：见[会话工具](session-tools.md)、[命令模式](cli-command-modes.md)及[任务计划](task-plans.md)。委派保持单层；计划功能默认关闭，启用后由现有 Agent 显式使用工具，不会增加模型调用或自动调度器。
- 记忆、图片输入、Web UI 与观测功能：对应选项见模板分组和[Web UI 文档](web-ui.md)。可选能力默认保持关闭。

## 常用安全选项

`TOOL_PERMISSION_POLICY` 默认 `standard`。`full_access` 会自动批准工具确认，但仍受注册开关、工具子集、路径和沙箱规则约束；请仅在可信环境中使用。命令联网默认关闭，开启后仍需使用公网单播白名单。`MODEL_TOOL_NAMES=null` 表示默认工具集，空数组表示禁用工具，显式列表会收窄可用工具。

`ENABLE_TASK_PLANS` 默认关闭；计划步骤上限默认 32，可配置为 1–256。上下文摘要长度默认 2000 字符，可配置为 256–16000；计划文件上限默认 65536 字节，可配置为 1024–1048576。任务计划记录进度和证据引用，不代表通用自动验收。
