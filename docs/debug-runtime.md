# Agent 运行调试

运行调试在 CLI 和 WebUI 中分别提供实时面板，用于观察各自进程的 Agent 活动、模块调用和因果时间线。面板只读运行时状态，不启动、暂停或修改 Agent。CLI 终端面板在 `DEBUG=true` 时自动显示；WebUI 调试页地址为 `/debug`。

## 启用

在 `.env` 中设置 `DEBUG=true` 并重启对应进程。CLI 使用普通启动命令：

```bash
uv run ai-agent-startup
```

WebUI 需安装可选依赖后启动：

```bash
uv sync --locked --extra web
uv run --locked --extra web ai-agent-web
```

重启 WebUI 后，打开 `http://127.0.0.1:8765/debug`。页面每 500 ms 以只读请求更新，使用 generation 与 cursor 合并事件；检测到服务重启、窗口缺口或游标重置时会重取完整窗口。暂停按钮冻结画面和轮询，Agent 与服务端记录继续运行；恢复后若窗口已滚动则重建当前窗口。详情仅在选中事件后读取，每页最多 6000 个字符，原始详情最多 1 MiB；超出上限会裁剪。服务重启后旧 generation 的详情返回 410，事件被容量淘汰后也不能再读取。CLI 面板每秒随终端重绘刷新，高 6 行，显示并发数量、最多 3 个活动调用和最近 2 个完成事件；活动调用包括父 Agent 标识。使用 `/debug off` 隐藏、`/debug on` 显示面板，命令也可从共享命令选择器中选择。隐藏面板不会清空事件窗口。

设置 `DEBUG=false`（默认值）并重启后，两个界面都不显示或记录运行调试事件。CLI 没有浏览器仪表板。

`DEBUG_TRACE_MAX_EVENTS` 同时控制时间线事件、legacy 完成 span 和活动调用的容量，默认 `512`，有效范围为 `1` 至 `10000`，越界值会限制到该范围。窗口达到上限后，较旧事件会淘汰；活动调用达到上限时，新调用会被忽略。页面显示淘汰或忽略数量，Agent 展示数量也受此容量限制。刷新或重连不会清空进程内记录；服务重启后窗口从空开始、generation 改变，不能恢复重启前窗口。事件不会写入用户目录。

## 页面内容

页面默认展示根 Agent 的行为、事件和异常总览；子 Agent 以紧凑行呈现，点击标签展开该 Agent 的完整行为时间线，再次点击收起。顶部工具栏可打开“查看通信详情”，默认总览只显示通信计数，不绘制全局通信连线。时间线支持缩放、暂停/恢复跟随最新及回到最新位置。详情按需读取：可查看脱敏元数据，并对关联的最终回复或工具调用/结果分页查看；普通快照不带正文，详情不包含 reasoning。密钥字段及已知凭据会在返回前脱敏。JSON 导出只在浏览器本地生成当前快照元数据，不包含事件正文或按需详情正文。

根 Agent 总览轨道默认高 224 px。每个父 Agent 使用共享的左右分流/汇流母线表示子 Agent 的调用关系，并覆盖后代工作范围以避免旧嵌套 trace 的连线相交；母线表达结构，不表示耗时，也不改变当前递归代理执行限制。子 Agent 默认高 72 px，只按真实起止时间显示 workline；未结束的活跃 Agent 不显示汇流。展开后的子 Agent 使用 224 px 行，显示完整行为。子 Agent 行内只在自身对应的起止事件之间画水平分流／汇流连接段，不画跨越多行的独立长曲线。行为标签避开母线通道，使用短竖箭头指向时间线；优先显示 Plan 和具体工具，Think / Loop 保留在详情中。工具调用与模块 span 可在对应事件详情中查看；明确展开模块 span 时，在单独区域显示细节并允许增加轨道高度。Agent 颜色首次分配后保持稳定，后续颜色会避开相近色相。默认视图不绘制 message-edge；概览提供通信计数入口。打开通信详情后，`#communication-routes` 按条显示 sender→recipient、发送/读取时间和 pending 状态；只依据真实发送与读取事件呈现，不把发送误画成送达或已读。消息保留原有 sent/read 分页与显式正文读取。精确时间异常使用红/橙色点提示，并有异常入口；摘要分别统计工具错误、拒绝和其它异常，tool 与 span 相关的重复事故按含 session、turn、tool_call_id 的事故 ID 去重，跨轮复用 tool_call_id 不合并，原始事件仍可定位。回放示例有 6 条局部通信，其中 2 条在收件 Agent 结束后发送并保持未读 pending；异常摘要为 5 个工具错误、1 个拒绝、Compact 0，原始异常记录 18 条，二者为不同计数口径。既有 4460 条事件、3 个 Agent 的回放不代表本轮新模型调用。概览另显示父 Agent、运行状态、Agent 数量和共同时间尺度上的事件密度趋势；事件密度只计时间窗中的事件数，不表示 CPU 使用率或任务时长。点击事件后，在下方分页列表逐页查看，每页 20 行；工具区域同一时间只展开一组，预览最多 6 次调用，其余调用可继续翻页查看。原始 JSON 元数据默认折叠。等待确认也计入阶段时间，停止后的空闲不计入。token 的 `provider`、`estimated`、`unknown` 语义与未知值留空规则不变。

空闲压缩默认开启时，仅折叠已由停止与下一次开始事件夹定、且确认期间没有活动任务或 span 跨越的全局空闲区间；活动模型/工具等待不会压缩。压缩段保留真实时长标签，横轴转为非等距；关闭控件可恢复等距时间轴。暂停刷新或系统偏好减少动态效果时，流动线和游标动画停止；活跃动画仅用细线上的低调流动标记提示状态。

上下文利用率图显示采样百分比，计算包含为当前用户输入及搜索预留的字符/token 空间；因此它是上下文预算占用估值，不是单纯历史内容比例。token 图可按请求或累计查看 input/output：`provider` 表示服务商 usage 报告，`estimated` 表示本地估算，`unknown` 表示无可靠用量且留空，不绘为零。token 历史只从启用 DEBUG 后采集，不是账单全历史；没有 DEBUG 事件的时间段不会补画数据。调试不额外调用 LLM。
WebUI 调试页还提供按会话查看结构化上下文归档的入口。该入口仅在 `DEBUG=true` 时可用；从工作区主上下文条打开时会定位到对应会话，Agent 卡片也可打开只读归档窗口。列表按最多 20 个块分页，显示 `manifest.json` 路径、修订号、会话摘要类型和块摘要类型；点击块后先查看摘要，再明确点击“读取原文”请求；每页最多 6000 个 Unicode 字符。页面展示块文件路径、摘要、时间、格式/类型信息，并可继续读取后续页。

归档读取会验证当前会话归属、索引与块标识，并校验原文 digest；摘要字段执行格式校验但没有独立 digest，并拒绝不安全的链接或非普通文件。返回浏览器前会隐藏已知主模型、运行时模型和监督器密钥；原文先脱敏再分页，磁盘存储不被改写。归档文件位于 `.agent/<session-id>/context/manifest.json` 和 `.agent/<session-id>/context/chunks/<chunk-id>.json`；块文件中的 `RawHistory` 是 JSON 字符串，原始消息日志仍位于会话目录的 `messages.jsonl`。压缩只缩短发给模型的上下文窗口，完整原文仍在归档中。普通调试 trace 与 JSON 导出仍只包含运行元数据，不包含摘要或原文；显式打开归档才会读取它们。

跟踪范围包括 `agent.run`、`model.total`、`model.request`、`tool.total`、`tool.execute`、`permission.confirm`、`persistence.save`、`communication.inbox`、`memory.load`、`plan.summary`、`context.prepare`、`context.compact`、`supervisor.inspect`、`supervisor.summary`，以及 RAG 的 `rag.index`、`rag.vector`、`rag.bm25`、`rag.rrf` 和 `rag.rerank`。模型流中的思考、输出、工具参数和状态只更新当前调用的活动标记，不会逐 token 产生事件。工具结果会区分拒绝、超时、取消等状态；持久化计时包含 writer 排队时间。

时间线仅保存固定类型的事件元数据、因果标识、状态、时间、白名单指标和异常类型，不保存模型正文、reasoning、工具参数、密钥或异常正文。工具事件只显示经过校验的工具名。监督器显示为模块节点，不代表单独执行的 Agent 会话。父子调用耗时可能互相包含，不应相加。此追踪与 `ENABLE_OBSERVABILITY` 的 CLI 指标及 `ENABLE_DEBUG_TOOL` 的模型调试工具相互独立。

WebUI 仍只监听回环地址，并沿用现有 Host、Origin 与访问令牌规则。CLI 与 WebUI 是不同进程，调试窗口不共用，不能跨进程读取；CLI 面板显示 CLI 进程的状态，Web 页面显示 WebUI 进程的状态。两个进程同时使用同一状态目录仍受单进程状态锁限制。

## 历史验证记录（2026-10-12）

以下记录针对当时的运行调试实现，不覆盖本轮新增的因果时间线验收。

新版 DEBUG 时间线显示规则以既有真实 trace 的 4460 个事件、3 个 Agent 回放验证；这是既有记录回放，不代表本轮新模型调用。

- `uv sync --locked` 与 `uv sync --locked --extra web` 均通过；没有新增依赖或修改锁文件。
- `uv run --locked --extra web pytest -m 'not integration' -q -rs --tb=short`：951 passed、2 skipped（可选 ANN 未安装）、5 deselected（真实模型集成测试）。其中新增运行调试 31 项、RAG 阶段 7 项回归，覆盖并发隔离、取消、拒绝、异常、容量、懒加载和真实文件工具；模型边界使用测试适配器，没有请求收费模型服务。
- `AUDIT_LOG=/tmp/agent-debug-sandbox-audit.jsonl uv run --locked --extra web python dev/ci_sandbox_probe.py`：Bubblewrap + prlimit 实际隔离执行通过。
- 浏览器使用独立临时状态目录和工作区，验证两个父子 Agent 执行真实 `read_file`，筛选、暂停刷新、JSON 下载均成功；导出包含 2 个 Agent、512 条保留事件和 2 个活动模块，没有文件正文。450 px 窄屏无横向溢出。测试实例与用户运行数据隔离。

开销微基准在 WSL2、CPython 3.12.14 中对同一 recorder 调用域循环 20,000 个空 span，重复 5 次取中位数：关闭 0.833 µs/span，开启 2.883 µs/span，增量约 2.050 µs/span。保留 512 条事件时，1,000 次快照的中位耗时为 41.31 µs；增加 4 个活动调用后为 43.30 µs，JSON 约 89 KB。这些数字仅表示追踪器的本机开销，不能代表完整模型任务的性能。
