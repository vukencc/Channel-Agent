# Flow 节点动态工具

> 当前使用说明 · [文档导航](README.md) · [配置示例](agent-flow.md#节点自定义工具) · [沙箱说明](sandbox.md)

节点携带私有的 `custom_tools` JSON 数组，在桌面或 Web 节点设置中编辑并选择；设计助手也能生成定义。保存、导出和导入只校验数据，不执行代码。运行前审查来源和代码，不要在定义中放凭据。

每项定义含 `name`、`description`、`parameters`、`code` 和可选 `network`（默认 `false`）。Pydantic 检查定义，参数采用受限 JSON Schema 2020-12：根为 object，不支持引用、正则或组合 schema；每节点最多 16 项，schema 最多 16 KiB、深度 12、128 个节点，每个对象最多 64 个属性。名称不得重复或覆盖已注册工具。Python 源码最多 32000 UTF-8 字节，须有一个只接受一个参数的同步 `main(arguments)`，返回可 JSON 序列化的结果。AST 检查语法和入口签名，并非安全沙箱。调用参数上限 64 KiB，执行前解析有限 JSON 并按 schema 验证。

定义随 Flow 和会话保存，以会话私有目录提供，不加入全局注册表。复用节点时使用当前定义替换旧定义。部署的 `MODEL_TOOL_NAMES` 必须允许 `run_command`；节点可隐藏通用命令工具而单独选择自定义工具。`tool_names: null` 继承部署目录，显式选择收窄目录，Flow 基础工具仍按其规则保留。子会话受父级及祖先工具上限约束，且只能继承与祖先完全一致的定义。有效 schema 用于预算、provider 和实际分派；校验缓存不会固定权限。

调用把有界源码及参数以 Base64 传入 `python3`，通过现有 `run_command` 在所选执行环境运行，沿用权限、确认、审计、网络策略、超时和取消。`network: true` 不覆盖部署策略。Windows 隔离命令通过 WSL，见 [Windows 指南](windows.md)。Flow local 命令与经典会话 local 语义不同，不能把所有 local 运行称为完全隔离；详见 [沙箱说明](sandbox.md)。

工具退出码 0 只证明进程正常退出；业务结果仍须按节点交接约定和产物独立验收。外部写入工具应使用幂等标识，结果未知时先核对产物再决定重试。

**选择自定义工具本质上授予其在当前执行环境中的命令能力**，即使节点没有暴露通用命令工具，也不能把它当作只读权限。代码可以尝试读写文件、调用进程或访问网络；实际边界取决于所选环境和策略。

## 安全验证与限制

| 情况 | 预期边界与验证方式 |
| --- | --- |
| 导入含顶层副作用的定义 | 校验不执行代码；测试以标记文件检查。 |
| 无效 schema、重复名称、覆盖内置工具或无效 Python | 定义校验拒绝，不启动命令。 |
| 参数类型不符、额外字段、非有限数字或超限 | 调用前拒绝；测试检查命令未调用。 |
| 部署禁用命令、节点未选择或祖先定义变化 | 工具不能成为有效能力；检查模型目录与分派。 |
| 项目外文件、宿主环境变量 | Linux 真实隔离测试检查不可见，且项目内写入成功；只证明该测试环境及探测范围。 |
| 确认拒绝、取消、网络、超时 | 沿用命令路径；针对策略和平台分别验证。 |
| Unicode、引号及接近上限的参数 | 真实隔离测试检查传递和结果。 |
| Windows | 原生桥接和 WSL 隔离需分别验证；不能以 Linux 结果代替。 |

## 审计与并发授权

自定义工具执行记录、允许的确认记录和命令启动记录采用严格审计：追加失败时阻止启动。命令产生副作用之后，如果完成审计追加失败，结果明确报告失败；不能称为成功，也不能断言命令未执行。应用配置 `AUDIT_SYNC` 默认 `false`，采用内核追加；设为 `true` 时每个事件执行 fsync，不能因此保证所有存储故障下的数据持久性。

会话通过短时执行授权锁协调工具设置变更。在等待工作区和用户确认之后、进程启动之前重新检查当前定义、祖先能力和取消状态。模型看到的 schema 快照可能已经过时，实际执行仍重新校验。Windows WSL 路径以 `command_started` 审计确认 ACK 作为授权提交点：提交前撤权阻止启动，已启动的命令不会因后续撤权自动回滚其副作用。

安全回归还包括对抗输入、授权竞态、入口契约和动态工具打包成品 smoke；最终结果和未测项见[安全验证报告](dynamic-tools-security-validation-2026-11-11.md)。
